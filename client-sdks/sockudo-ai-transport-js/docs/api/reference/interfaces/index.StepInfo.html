    Interface StepInfo

    State of one logical step within a run.

    A step is re-attemptable: a retry publishes a fresh ai-step-start under the same step-id, and the attempt with the highest step-start-serial is canonical. Output stamped with a superseded attempt's serial is ignored, so a failed attempt's partial output never reaches the projection.
